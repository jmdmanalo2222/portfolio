UPDATED WEBSITE DEMO

Open index.html in a modern browser. HTML, CSS, JavaScript, and real stock photographs are bundled locally. No dependencies or build step are required.

Upload every file and the assets/ folder together to the existing website directory. Keep the original filenames and relative paths.
